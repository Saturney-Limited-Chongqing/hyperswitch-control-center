# 中文中台功能对应表

界面参考彩虹易支付开源版的 `admin/head.php`、`admin/index.php`、`user/head.php` 和 `user/index.php`：平台端按「首页／收款订单／商户管理／支付接口／系统设置」组织，商户端按「用户中心／个人资料／查询」组织。只借鉴信息架构和 Bootstrap 风格，不复制其支付插件、数据库或后端权限模型。

| 彩虹后台概念 | 本项目平台端 | 本项目商户端 | 现有实现 |
| --- | --- | --- | --- |
| 平台首页／用户中心 | 平台首页与商户列表 | 商户收款概览 | `/platform`、`/home` |
| 订单管理 | 各授权商户的订单 | 当前商户订单 | `/payments` |
| 退款 | 各授权商户退款 | 当前商户退款 | `/refunds` |
| 支付用户统计 | 交易分析 | 收款分析 | `/analytics-payments` |
| 商户管理 | 商户列表与切换 | 无平台商户操作 | `/platform`，后端授权决定可见商户 |
| 支付通道 | 渠道账户管理 | 只查看支付结果 | `/connectors`，后端拒绝商户管理权限 |
| 通道限额／轮询 | 每日限额与路由规则 | 不可修改 | `/platform/channel-limits`、`/routing` |
| API 信息 | API 密钥 | 当前商户 API 密钥 | `/developer-api-keys` |
| 回调通知 | 回调配置 | 当前商户回调 | `/webhooks` |
| 用户管理 | 平台/商户用户 | 当前商户用户 | `/users`，后端实体权限生效 |
| 个人资料 | 当前账户资料 | 当前账户资料 | `/account-settings/profile` |

彩虹的余额、结算、代付、提现、分润、公告等业务能力不能仅靠界面添加。现有 Hyperswitch 或本项目的后端没有对应的完整租户账本/结算语义时，不显示这些入口，也不展示虚构金额。上游的风控、对账、复杂编排等已有能力通过平台端「高级功能」继续可用；它们需要按实际使用频率逐页中文化。

授权规则始终由后端执行。商户不能因直接输入路由或渠道 URL 而获得平台权限。界面仅根据角色和资源权限决定导航与提示。
